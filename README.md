# Project Overview:
- This project focuses on analyzing Blinkit sALES DATA USING mICROSOFT excel. The main objective is to understand sales performance, products categories and outlet performance through data analysis and an interactive dashboard.
# Project Objective
- Analyze overall sales performance.
- Identify highest and lowest selling product categories.
- compare sales based on fat content.
- Analyze outlet performance  by size and location.
- Understand sales trends across outlet establishmen years.
- Create an interactive dashboard for business insights.

# Data Analysis Performed
- KPI Analysis: Total Sales, Average Sales, Number of items and Average Rating.
- Fat Content Analysis: Compared Low Fat and Regular product sales.
- Item Type Analysis: Analyzed sales across different product categories.
- Outlet Establishment Analysis: Compared sales by establishment year.
- Outlet Size Analysis: Analyzed sales by outlet size.
-  Outlet Location Analysis: Compared total sales across Tier 1, Tier 2, Tier 3.
-  Outlet Type Analysis: Compared total sales, average sales and number of items across outlet types.
# Key Insights:
- Low Fat Products contributed 65% of total sales.
- Fruits and vegetables recorded the highest  sales among  item categories.
- Outlet establishment in 2018 recorded the highest sales.
- Medium-sized outlets generated the highest sales.
- Tier 3 locations recorded the highest sales.
- Average customer rating was 4.0.
